Macchina Monitor

Projeto de monitoramento automotivo desenvolvido com HTML, CSS e JavaScript.

Sobre o projeto

O Macchina Monitor é uma interface demonstrativa inspirada em painéis de monitoramento automotivo. O objetivo é praticar desenvolvimento web e simular a visualização de informações do motor em tempo real.

Funcionalidades

- Painel com conta-giros (RPM).
- Acelerador interativo.
- Indicadores simulados de pressão do turbo, temperatura e pressão do óleo.
- Controles para ligar e desligar o monitoramento.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

Observação

Este projeto é uma simulação para fins de estudo. Os dados exibidos não vêm de sensores reais nem de uma central eletrônica automotiva.
